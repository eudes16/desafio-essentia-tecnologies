# Todo App - Desafio Essentia Tecnologies

Projeto de uma aplicação de lista de tarefas

## Funcionalidades

- Listar tarefas
- Adicionar tarefas
- Atualizar tarefas
- Marcar tarefas como concluídas
- Remover tarefas

## Requisitos

- Backend:
  - NodeJS
  - TypeScript
  - Banco de dados MySQL
  - Banco de dados MongoDB (opcional)

- Frontend:
  - Angular 14+
